Run output lives here (`runs/first_gym_001/` and friends). The dataset is only `steps.jsonl` plus `frames/*.png`: one JSONL line per held action with `{image, start, end, inputs}`, where `start`/`end` are inclusive PyBoy `frame_count` values, hold length is `end - start + 1` in `{8, 16, 24, 32}`, and `image` is a 160×144 PNG of the LCD at `start` before those buttons are applied. Do not commit ROMs, PNGs, JSONL, or `.state` files.
